## 📖 Overview
This repository contains a professional **Power BI Data Model** focused on transforming raw, unorganized business datasets into a clean, scalable, and analytics-ready **Star Schema** using industry-standard Business Intelligence practices

The primary goal of this project goes beyond basic dashboard visualization—it demonstrates the end-to-end engineering lifecycle required to build a performant, maintainable, and business-ready semantic model

---

## 🛠️ Tech Stack
* **Tooling**: Microsoft Power BI Desktop, Power Query (M), DAX
* **Data Sources & Formats**: Excel / CSV Datasets
* **Version Control**: Git & GitHub

## 🗺️ Project Roadmap & Modeling Methodology

### Phase 1 — Prepare & Explore
The first step is to understand the data before making transformations.
* Understand the business process
* Understand the business domain
* Identify entities
* Identify fact tables
* Identify dimensions
* Understand relationships
* Understand the grain
* Identify duplicate and unnecessary data
